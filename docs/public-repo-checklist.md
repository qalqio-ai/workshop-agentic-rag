# Public Repository Release Check

Complete before the first push and whenever adding a new source corpus.

- [ ] Confirm the legal rights holder in LICENSE.
- [ ] Review staged files for credentials, private data, customer material, and internal-only information.
- [ ] Confirm every demo source is synthetic or approved for public redistribution.
- [ ] Confirm .env files, local model outputs, private corpora, and credentials are ignored.
- [ ] Check screenshots, logs, and evaluation fixtures for sensitive data.
- [ ] Confirm description, topics, and default branch.
- [ ] Review organization branch protection and security settings.
- [ ] Run secret scanning or an equivalent check.
- [ ] Record the commit and reviewer.
