title: Workshop Quickstart
---

Install project dependencies from the repository instructions, copy the example environment file, then start the FastAPI service with Uvicorn.

Open the interactive API documentation at the local /docs path. Ingest only fictional or public workshop material.

The API uses a deterministic mock model by default. A live OpenAI Responses API model can be enabled by setting MODEL_PROVIDER to openai and supplying an API key through the environment.
